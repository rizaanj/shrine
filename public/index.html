Get started with Shrine

Check your app for security issues in 5 minutes

Step 1: Install Shrine
Open your terminal and run this command. It downloads Shrine to your computer.
npm install -g shrine-cli
What you should see:
A bunch of text scrolling by, then "added 1 package" or something similar. Takes about 30 seconds.
Step 2: Create an account
Scroll to the login section at the bottom of this page and sign up. You'll get an access key - copy it.
What you should see:
After signing up, you'll see a box with your access key. It looks like a random string of letters and numbers. Click "Copy to Clipboard".
Step 3: Connect your account
Paste your access key into this command where it says YOUR-KEY-HERE, then run it.
shrine login YOUR-KEY-HERE
What you should see:
"Authentication successful" or "Logged in". That's it.
Step 4: Go to your project folder
Use the cd command to go to your project. Replace "my-app" with your actual folder name.
cd my-app
What you should see:
Your terminal prompt changes to show your project folder name. Nothing fancy.
Step 5: Run the scan
This checks your code for security problems. Takes 1-2 minutes depending on project size.
shrine scan
What you should see:
Either "No issues found" (good news!) or a list of problems with file names and line numbers. The report shows what's wrong and where.

Stuck?

"Command not found" or "shrine is not recognized"
The install didn't work. Try closing your terminal completely and opening a new one. If still broken, you might need to install Node.js first from nodejs.org.
"Invalid access key" or "Authentication failed"
You copied the key wrong or it has extra spaces. Go back to step 2, get a fresh copy of your key, and paste it carefully into the login command.
"Not a git repository" or "No .git folder found"
You're in the wrong folder, or your project isn't using git. Use "cd" to go to your actual project folder where you code lives.
Still stuck? Email us and we'll help you out.

What the report means

CRITICAL
Really bad. Like your password or payment keys are visible in your code. Fix this immediately before anyone else finds it.
HIGH
Your database or user data could be accessed by people who shouldn't see it. Fix this today.
MEDIUM
Not an emergency, but makes your app less secure. Fix when you have time, maybe this week.
LOW
Minor stuff that's good to clean up eventually. Won't cause immediate problems.
